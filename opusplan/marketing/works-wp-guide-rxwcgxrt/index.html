OPUS PLAN ─ WORKS

実績ページ WordPress掲載ガイド
新しいデザインを本番サイトに載せるまで

実績の一覧ページと詳細ページを、新しいデザインに差し替えるための手順書です。
コーダーさんにお願いする部分と、管理画面で高寺が行う部分を分けて整理しました。

作成：2026年10月27日（同日 担当メンバーの項目を追記）　／　高寺　／　対象：opus-plan.net 実績（カスタム投稿タイプ works）

1

このガイドについて

実績ページ（一覧・詳細）のデザインを新しくします。そのために本番サイト側で必要な作業をまとめました。

完成イメージは、実際の opus-plan.net のページに新しいパーツを差し込んだ形で確認できます。デザインの正はこの2つです。

実績一覧https://kanpai-web.github.io/share/opusplan/marketing/works-list-k7md2q4p/
実績詳細https://kanpai-web.github.io/share/opusplan/marketing/works-detail-r3xn8vwe/

先に結論

関連実績はすでに動的に出力されています（投稿をループして出している）ので、仕組みを作り直す必要はありません。
いちばん手数がかかるのは、新しいカードが表示する「業種」「成果」「見出し」「規模・支援期間」「成果の数値」が、いまの実績に存在しないことです。ここを足す作業が本体になります。

本番サイトを調べて分かったこと

調べたこと分かったこと
実績の投稿場所カスタム投稿タイプ works。URLは /works/<サービス>/<スラッグ>/
実績詳細の本文the_content() がテンプレートで呼ばれていません。いま本文欄に書いても画面に出ません（STEP 1 で追加をお願いします）
いまの絞り込みサービス4分類（SEO対策・広告運用代行・風評被害対策・その他）のリンク。クリックでアーカイブURLへ遷移します

だれが、何をするか

コーダーさん

1回だけ・テンプレート側

  • CSS（opus-works.css）の設置と読み込み

4

STEP 1　CSSの読み込みと、本文の出力

ここまでで、実績詳細のページが新しいデザインになります。コーダーさんの作業は実質2か所です。

① CSSファイルを置く

opus-works.css をお渡しします。テーマ内の任意の場所（例：assets/css/）に置いて読み込んでください。既存の style.css や reset.css は変更していません。

クラス名はすべて ow-（詳細）／owl-（一覧）で始めてあるため、他のページに影響しません。色はファイル冒頭の :root でまとめて変えられます。

functions.php（読み込みの例）
// functions.php
// 実績ページ（一覧・詳細）でだけ読み込む
add_action( 'wp_enqueue_scripts', function () {
    if ( is_singular( 'works' ) || is_post_type_archive( 'works' )
         || is_tax( array( 'work_category', 'area_category', 'part' ) ) ) {
        wp_enqueue_style(
            'opus-works',
            get_theme_file_uri( '/assets/css/opus-works.css' ),
            array(),
            filemtime( get_theme_file_path( '/assets/css/opus-works.css' ) )
        );
    }
} );

② 実績詳細に本文の出力を追加する

いまのテンプレートでは the_content() が呼ばれていないため、本文欄に何を書いても画面に出ません。1行だけ追加をお願いします。

single-works.php に追加
<?php // single-works.php ?>
<?php // 「実績エリア」のブロック（p-work__content-area）の直後に置いてください ?>
<?php if ( get_the_content() ) : ?>
  <div class="p-work__detail"><?php the_content(); ?></div>
<?php endif; ?>

自動整形について

お渡しする本文は、div と p で構造が閉じた素のHTMLです。ブロックエディタのマークアップは使っていません。もし wpautop で余計な <p> が入って崩れる場合は、ご相談ください（本文側で調整します）。

この時点で確認できること

1件に本文を入れれば、PROBLEM／REQUEST／APPROACH／RESULT／NEXT／REASON とサマリーの追従まで、詳細プレビューと同じ見た目になります。

① 業種・成果のタクソノミーを追加

どちらも絞り込みに使うので、自由入力ではなくチェックで選ぶ形にしてください。

functions.php（タクソノミーの例）
// functions.php
// 新しい絞り込み軸：業種 と 成果
add_action( 'init', function () {

    register_taxonomy( 'work_industry', 'works', array(
        'label'        => '業種',
        'hierarchical' => true,          // チェックボックスで選ばせる
        'public'       => true,
        'rewrite'      => array( 'slug' => 'works/industry' ),
        'show_in_rest' => true,
    ) );

    register_taxonomy( 'work_result', 'works', array(
        'label'        => '成果',
        'hierarchical' => true,
        'public'       => true,
        'rewrite'      => array( 'slug' => 'works/result' ),
        'show_in_rest' => true,
    ) );

} );
業種のターム（案）葬儀・終活／建設・リフォーム／医療・クリニック／不動産／士業／製造・メーカー／飲食・店舗／教育・スクール
成果のターム（案）問い合わせが増えた／検索順位が上がった／アクセスが増えた／広告費を抑えられた

タームの実際の並びは、既存の実績を見ながら高寺のほうで決めます。まずは上記で作っていただければ大丈夫です。

あわせて「担当メンバー」の分類もお願いします

会社概要のメンバー紹介で、メンバーごとに「担当した実績」の最新3件を自動で出すために使います（カードや絞り込みには出しません）。登録コードと表示の仕組みはメンバー紹介のガイド（STEP 2・STEP 4）にまとめています。

② カスタムフィールドの入力欄を用意

本文に決まった書式で書かせる方式は、入力ミスで崩れるため採りません。管理画面に入力欄が並ぶ形にしてください。

キー（案）ラベル入ってくる値の例
work_card_titleカード見出し大阪府堺市 葬儀社｜地域SEO対策で問い合わせ8倍
work_card_meta規模・支援期間従業員15名・年商3億円規模／支援期間 1年6ヶ月
work_kpi_label成果の項目名お問い合わせ

ご確認いただきたいこと

ACF などのカスタムフィールド用プラグインがすでに入っているかどうか、こちらからは分かりませんでした。入っていればそれを使ってください。入っていない場合は、どの方法が運用しやすいかご提案いただけると助かります。

空のときの扱い

成果の数値が入っていない実績もあります。値が空のときは RESULT のブロックごと出力しないようにしてください（枠だけ残ると不自然になります）。見出しが空のときは、会社名を代わりに出す形で構いません。

6

STEP 3　データを入れる（高寺の作業）

STEP 2 の入力欄ができたら、既存の実績に順番に入れていきます。

  1. 実績改善シートに、実績ごとの「業種・成果・見出し・規模／支援期間・成果の数値」の列を用意する
  2. 既存の実績の本文を読みながら、シート上で全件ぶんを書き出す
  3. 管理画面で1件ずつ転記する。「担当メンバー」に担当した人全員のチェックも入れる

先にシートで揃えてから転記したほうが、言い回しのばらつきが出ません。新しく実績を追加するときは、最初から入力欄を埋めるだけになります。

実績を公開するたびに：担当メンバーのチェック

チェックを入れた人のプロフィール（会社概要のメンバー紹介）に、その実績が自動で並びます。チェックを忘れると、どのメンバーにも表示されません。

成果の数値が無い実績

数値が出せない実績は、無理に埋めずに空のままで構いません。RESULT のブロックごと出ない作りにしてあります。

7

STEP 4　実績一覧を差し替える

カードのマークアップと、4軸の絞り込みUIをお渡しします。実績一覧_マークアップ.html が正です。

絞り込みの仕様

  • 4つの軸（業種／エリア／サービス／成果）をタブで切り替え、その中のチップを押して絞り込みます
  • 絞り込みはページ遷移せず、JavaScriptで表示を切り替える方式です。カードの data-ind / data-area / data-svc / data-res を見ています
  • カード内のタグを押しても同じ絞り込みが動きます
  • SP（600px以下）ではタブとチップをやめ、選択メニュー1つに置き換わります。タップ先が1か所に集まり、レイアウトが動きません
  • 件数表示とページネーション（12件ずつ）も同梱しています

全件をHTMLに出してください

絞り込みはJavaScriptで行うため、実績は全件を出力してください（ページネーションもJS側で処理します）。件数が大きく増えた場合は、サーバー側での絞り込みに切り替えるご相談をさせてください。

STEP 5　関連実績を横スクロールにする

カードを一覧と同じものに揃え、横スクロール（ループ）に変えます。マークアップとスクリプトは 実績詳細_関連実績マークアップ.html が正です。

仕様

  • 表示するのは、その実績と同じサービスの実績。最大8件、4件に満たないときだけ新着で補います
  • 操作はドラッグと左右ボタンの2つ。ボタンはカード1枚ぶん送ります
  • ループさせるため、同じカードを2周ぶん出力します。端まで行くと切れ目なく先頭に戻ります
  • 右端のカードがわざと見切れるようにしています（横に続きがあることを示すため）

いまのスライダーを外してください

関連実績には slick のマークアップ（slick-list / slick-track）と、高さを固定するCSS（.p-results__items{height:43vh}）が効いています。このままだとカードが途中で切れます。新しい横スクロールと二重になるため、関連実績のスライダー初期化は止めてください。

関連実績のPHP（参考実装）

single-works.php の関連実績部分
<?php
/**
 * 関連実績（Related Works）
 * いまの関連実績の出力を、このループに置き換えてください
 */
$svc_terms = get_the_terms( get_the_ID(), 'work_category' );
$svc_ids   = ( $svc_terms && ! is_wp_error( $svc_terms ) ) ? wp_list_pluck( $svc_terms, 'term_id' ) : array();

$args = array(
    'post_type'      => 'works',
    'post_status'    => 'publish',
    'posts_per_page' => 8,
    'post__not_in'   => array( get_the_ID() ),   // 自分自身は除く
    'orderby'        => 'date',
    'order'          => 'DESC',
);
if ( $svc_ids ) {
    $args['tax_query'] = array(
        array(
            'taxonomy' => 'work_category',
            'field'    => 'term_id',
            'terms'    => $svc_ids,
        ),
    );
}
$rel = new WP_Query( $args );

// 一致が4件に満たないときだけ、新着の実績で補う
if ( $rel->post_count < 4 ) {
    $have = wp_list_pluck( $rel->posts, 'ID' );
    $fill = get_posts( array(
        'post_type'      => 'works',
        'post_status'    => 'publish',
        'posts_per_page' => 4 - $rel->post_count,
        'post__not_in'   => array_merge( $have, array( get_the_ID() ) ),
    ) );
    $rel->posts      = array_merge( $rel->posts, $fill );
    $rel->post_count = count( $rel->posts );
}

if ( $rel->post_count ) : ?>
<div class="ow-rel">
  <div class="ow-rel__track" data-rel-loop>
    <?php // ループさせるため、同じカードを2周ぶん出力する
    for ( $pass = 0; $pass < 2; $pass++ ) :
        foreach ( $rel->posts as $p ) :
            setup_postdata( $GLOBALS['post'] = $p );
            get_template_part( 'parts/works-card' );   // ← STEP 4 と同じカード
        endforeach;
    endfor;
    wp_reset_postdata(); ?>
  </div>
  <div class="ow-rel__nav">
    <div class="ow-rel__btns">
      <button type="button" class="ow-rel__btn" data-rel-prev aria-label="前の実績へ">
        <svg viewBox="0 0 24 24" aria-hidden="true"><path d="M15 5 8 12 15 19" stroke-linecap="square" stroke-linejoin="miter"/></svg>
      </button>
      <button type="button" class="ow-rel__btn" data-rel-next aria-label="次の実績へ">
        <svg viewBox="0 0 24 24" aria-hidden="true"><path d="M9 5 16 12 9 19" stroke-linecap="square" stroke-linejoin="miter"/></svg>
      </button>
    </div>
  </div>
</div>
<?php endif; ?>

カードは共通です

関連実績のカードは、STEP 4 の実績カードとまったく同じものです。テンプレートパーツとして切り出して、一覧と関連実績の両方から呼ぶ形にしていただけると、以降の修正が1か所で済みます。

公開前のチェック

プレビューと見比べながら確認してください。

  • 実績詳細の本文が表示され、サマリーがスクロールに追従する（固定ヘッダーの下で止まる）
  • ヒーローのタグが、サービスごとの絞り込み結果ページに遷移する
  • RESULT の数字と黄色いマーカーが出ている
